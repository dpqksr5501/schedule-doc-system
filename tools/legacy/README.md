# v1 개발 과정의 보관 자료

이 폴더는 이전 버전의 일회성 패치·양식 분석·배포 스크립트를 보존합니다.
현재 프로그램 실행이나 빌드에 사용하지 않습니다. 과거 하드코딩 경로와
코드 덮어쓰기 동작이 있으므로 그대로 실행하지 마세요.

현재 실행: 루트 `main.py` 또는 `dist/GunsuSchedule.exe`.
현재 빌드: 루트 `build_release.py` / `build_exe.bat`.
현재 검증: 루트 `run_tests.py` 및 `tests/`.

초기 샘플 일정은 v2에 자동 입력하거나 실행 파일에 포함하지 않습니다.
