군수실 일정 관리 — 개발자용 배포·업데이트 안내
작성 기준: 2026-10-15 / 준비된 버전: v2.1.4

1. 사용자에게 안내할 파일

  GitHub 표시: 군수실 일정 관리 v2.1.4 (ZIP · 권장)
  다운로드명: GunsuSchedule-v2.1.4-Windows.zip
  로컬 ZIP명: 군수실 일정 관리-v2.1.4-Windows.zip
    ├ 군수실 일정 관리 설치.exe
    ├ 처음사용_5분안내.html
    └ 사용설명서.txt

압축을 푼 뒤 한글 설치 EXE를 한 번 실행합니다. 관리 폴더로 복사·검증하고
설치된 프로그램으로 전환한 뒤, 화면과 일정이 준비되면 기존 한글 바로가기를 갱신합니다.
압축 해제만으로 설치되지 않습니다. 예전 폴더를 찾아 직접 덮어쓰지 않습니다.
기존 창이 열려 있으면 저장하고 닫은 뒤 설치 안내에서 [다시 시도]를 누릅니다.
다운로드한 설치 파일을 계속 실행할 필요 없이 기존 바탕화면 바로가기를 사용합니다.

일정과 출력 문서, 백업을 설치 프로그램에서 삭제하지 않습니다.
원본 일정: %APPDATA%/GunsuSchedule/schedule_data.json
출력 문서: 실제 바탕화면/군수실_일정_출력문서
설치 프로그램: %LOCALAPPDATA%/GunsuSchedule/versions/<버전>/군수실 일정 관리.exe

2. 소스·버전·태그

변경을 검토하고 테스트한 뒤 소스를 커밋·반영합니다. 일정·백업·로그를 커밋하지 마세요.
app_info.py의 VERSION은 2.1.4이며 태그는 v2.1.4입니다.

  git tag v2.1.4
  git push origin v2.1.4

태그 생성·push는 공개 GitHub를 변경하는 작업입니다. 이미 공개한 태그나 실행 파일을
덮어쓰지 말고 이후 변경은 새 버전을 사용하세요. dist와 release는 소스에 포함하지 않습니다.
assets/branding의 JPG 4개와 branding.py는 실행에 필요한 소스 리소스입니다.

3. Actions 빌드와 검증

고정 의존성 → Python·JavaScript 검사 → EXE 빌드 → 격리된 EXE 검사 → WebView2 검사
→ 한글 설치 파일의 관리 폴더 복사·재실행·바로가기 전환 검사 순서로 진행합니다.
태그와 VERSION이 다르거나 검증에 실패하면 배포 초안을 만들지 않습니다.
정식 공개 상태는 GitHub Releases에서 확인하세요. main 반영만으로 공개되지 않습니다.

4. 초안 첨부 파일

  GunsuSchedule-v2.1.4-Windows.zip              사용자용 묶음 (한글 표시명)
  GunsuSchedule.exe                            구버전 앱의 업데이트 호환용
  SHA256SUMS.txt                               공개 EXE와 ZIP의 SHA256
  release-manifest.json                        버전·파일명·크기·SHA256

GitHub는 업로드한 파일명에서 한글을 제거하므로 한글 EXE를 직접 올리면 default.exe로
바뀝니다. 사용자에게는 한글 설치 EXE가 들어 있는 ZIP을 한글 표시명으로 안내합니다.
로컬 ZIP과 공개 ZIP의 내용·해시는 같습니다. 공개 manifest와 SHA256SUMS는 실제
공개 파일명에 맞춰 자동 준비합니다. 한글 설치 EXE는 별도 공개 asset으로 올리지 않습니다.
한글 설치 EXE와 호환용 EXE의 내용·해시는 같습니다. 구버전 앱은 고정된 영어 asset 이름을
찾으므로 호환용 파일도 첨부해야 합니다. 새 앱은 한글 asset을 우선하고 영어 asset도 지원합니다.
ZIP에 영어 실행 파일을 중복으로 넣지 않습니다.
릴리즈 설명은 docs/releases/v2.1.4.txt에서 읽습니다.
초안 검토 후 정식 공개해야 앱에서 업데이트로 보입니다.

5. 업데이트 확인

공개 릴리즈 API:
https://api.github.com/repos/dpqksr5501/schedule-doc-system/releases/latest

새 태그, EXE와 ZIP의 이름·표시명·size·sha256 digest, ZIP 안의 한글 설치 파일을 확인합니다.
SHA256이나 출처가 다르면 실행하지 않습니다. ZIP만 게시하면 앱 내 업데이트는 되지 않습니다.
v2.1.4에서 v2.1.4는 같은 버전이며 다음 정식 버전(v2.1.5 등)으로 운영 갱신을 확인해야 합니다.
가짜 버전이나 이전 EXE를 새 버전으로 올리지 마세요.

새 프로그램은 정상 시작 후 바로가기를 전환하고 이전 버전은 복구용으로 보관합니다.
복사 후보를 검증하기 전에는 설치 파일을 교체하지 않습니다.
바로가기 저장에 실패하면 활성 버전 기록을 되돌립니다.
최신 설치가 확인되면 오래된 설치 파일로 되돌리지 않습니다.
일정 형식의 자동 다운그레이드는 하지 않습니다.
기관 한글의 실제 HWP 변환·인쇄와 공개 Release를 통한 운영 갱신은 별도로 확인해야 합니다.

6. 구버전 자료

기존 프로그램에서 전체 일정 백업을 먼저 저장하세요.
v1 임시 브라우저 저장소는 실행 경로가 달라지면 보이지 않을 수 있으므로
일정이 비어 있으면 백업 파일 선택으로 건수·기간을 확인한 뒤 가져옵니다.
설치 파일이 기존 브라우저 저장소의 모든 경로를 찾아 복구하는 것은 아닙니다.
