사용 방법과 저장 위치

처음 사용하신다면 짧은 안내부터 보세요.
처음 사용 5분 안내 열기 — 인쇄해서 책상 옆에 두셔도 됩니다.
일정 입력 → 양식과 날짜 선택 → 한글 저장 순서로 진행합니다.

1. 처음 실행하기

  1. 배포 파일을 내려받습니다. ZIP으로 받았다면 먼저 압축을 풀어 주세요. 마우스 오른쪽 버튼 → 압축 풀기를 선택합니다.
  2. 압축을 푼 폴더 안의 GunsuSchedule.exe를 두 번 누릅니다. 실행 파일만 받았다면 그 파일을 실행합니다.
  3. 첫 실행이 정상 완료되면 바탕화면에 군수실 일정 관리 바로가기와 군수실_일정_출력문서 폴더가 준비됩니다.

다음부터는 바탕화면 바로가기를 사용하세요. 파이썬이나 VS Code 같은 개발 도구는 설치하지 않아도 됩니다.

기관에서 실행을 제한하거나 WebView2가 없다는 안내가 나오면 전산 담당자에게 확인을 요청해 주세요.

2. 일정 입력·수정하기

  1. ＋ 새 일정을 누릅니다.
  2. 일자·시작 시간·행사명을 입력하고, 장소와 주관부서를 확인합니다.
  3. 참석 구분에서 군수님 참석 / 부군수님 참석 / 일반·부서 행사를 고릅니다.
  4. 저장하기를 누른 뒤 화면 위쪽의 저장 완료를 확인합니다.

행사명을 누르면 수정창이 열립니다. 고친 뒤 다시 저장하기를 눌러 주세요.

미확정은 담당자에게 확인이 필요한 일정입니다. 취소는 전체 목록에 남지만 일반 일정표에서는 빠집니다. 참석 구분과 중요 표시는 별도로 선택할 수 있습니다.

3. 한글 저장·인쇄하기

  1. 왼쪽에서 일일 일정표 / 주간 행사계획 / 월간 일정표를 선택합니다.
  2. 화면 위의 날짜를 확인합니다. 주간은 그 날짜가 속한 월~일, 월간은 해당 달 전체입니다.
  3. 미리보기 내용을 확인하고 한글 저장 (.hwp)을 누릅니다.
  4. 저장 결과 안내를 확인합니다. 파일이 있는 폴더가 열리며, 저장한 파일 보기로도 찾을 수 있습니다.
실제 HWP 저장에는 Windows용 한글이 필요합니다.
HWPX를 열 수 있는 한글 버전이어야 합니다. 파일 접근 승인창이 나타나면 이번에 만든 문서 경로를 확인하고 허용해 주세요. 최대 90초까지 기다립니다.
양식과 용지 방향
양식출력 내용
일일 · 세로 A4큰 제목, 시간, 행사명, 오른쪽 장소. 주말에는 토·일 한 장에 묶기를 사용할 수 있습니다.
주간 · 세로 A4일자·시간·행사명·장소·부서 표. 날짜를 묶고 군수님 초록색 / 부군수님 파란색 / 일반 검정색으로 표시합니다.
월간 · 가로 A4월요일부터 일요일까지의 달력. 월초·월말을 포함하고 주말 날짜는 빨간색으로 표시합니다.

HWPX 저장은 HWPX 형식이 필요할 때 선택합니다. 인쇄 / PDF에서는 프린터 또는 PDF 저장을 선택합니다. A4 용지 방향과 페이지 수를 미리보기에서 확인해 주세요. 내용이 많으면 여러 장으로 이어집니다.

브라우저 인쇄에서 주소나 날짜가 머리글·바닥글에 붙으면 해당 옵션을 꺼 주세요. 화면의 용지 전체 보기는 화면 크기에만 영향을 주며, 한글 저장과 인쇄는 A4 기준입니다.

{{OUTPUT_PATH}}
폴더보관하는 내용

바탕화면이 OneDrive나 기관 지정 위치에 있어도 Windows가 알려주는 실제 위치에 출력 폴더를 만듭니다.

5. 주석·업무 메모 사용하기

행사명을 눌러 수정창을 열면 기록할 수 있습니다.

기록할 내용입력 예시출력 방식
출력 주석주민 대표 3명 참석 · 군수님 인사말 3분출력 주석 포함 선택 시 행사 아래 표시
상세 업무 메모참석 예정자, 담당 연락, 인사말·이동 준비, 전달사항, 준비 체크리스트상세 업무자료 첨부 선택 시 뒤쪽 별도 참고 페이지
기본 문서에는 주석과 상세 메모가 빠집니다.
필요한 경우에만 출력 옵션을 선택하세요. 내부 연락사항과 전달사항을 배부해도 되는지 확인해 주세요. 전체 데이터 백업에는 메모와 체크리스트도 포함됩니다.

예를 들어 준비사항에 ‘13:40 현장 도착 → 좌석 확인 → 인사말 자료 전달’을 적고, 확인 목록에 ‘인사말 인쇄’, ‘차량 동선 확인’을 나누어 등록하면 완료 여부를 관리하기 편합니다.

6. 실수 복구·백업하기

상황사용할 기능
방금 내용을 잘못 고쳤을 때되돌리기. 현재 실행 중인 동안 최근 30번의 변경을 기억합니다.
일정을 잘못 삭제했을 때휴지통 → 복원. 메모와 준비 확인 목록도 복원합니다.
큰 변경을 하기 전·정기 보관백업 · 복원 · 업데이트 → 지금 백업하기
이전 전체 상태로 되돌릴 때자동 백업에서 복원 또는 백업 파일 선택
전체 백업 복원은 현재 일정을 백업 내용으로 바꿉니다.
복원 전에 현재 상태를 백업하고, 안내창의 날짜 범위·일정 건수를 확인하세요.

PC 고장에 대비하려면 백업 파일을 기관에서 정한 안전한 저장 위치에도 따로 보관하세요. 같은 PC 안의 백업만으로는 PC 전체 고장에 대비하기 어렵습니다.

7. 반복 일정·빠른 입력

주간 화면에서 지난주 일정 가져오기를 누르고 필요한 행사만 선택합니다. 동일 일정은 건너뛰며, 가져온 일정은 미확정으로 등록됩니다. 날짜와 내용을 확인한 뒤 확정하세요.

참석자·메모 복사는 별도 선택입니다. 준비 확인 목록은 미완료로 바뀝니다.

빠른 입력에 ‘10/15 14:00 지역 현안 간담회’처럼 적고 내용 확인을 누르면 입력창이 채워집니다. 확인 후 저장하기를 눌러야 등록됩니다.

8. 문제 해결하기

저장한 일정이 화면에 보이지 않아요.

선택한 날짜를 확인하세요. 일일 화면의 군수님 참석만이 켜져 있으면 부군수님·일반 행사는 빠집니다. 체크를 해제하거나 전체 일정 · 검색에서 행사명을 찾아보세요. 취소 일정도 일반 출력에서는 빠집니다.

HWP 저장에 실패했다고 나와요.

이 안내가 나오면 HWP 저장이 완료된 상태가 아닙니다.
생성 내용은 HWPX 중간 문서로 남습니다. HWPX 중간 문서 보기 → 한글에서 열기 → 다른 이름으로 저장 → 한글 문서 (*.hwp)를 선택하세요.
한글이 없거나 HWPX를 열지 못하면 전산 담당자에게 한글 설치와 자동화 사용 가능 여부를 확인받으세요.

일정 저장 실패 / 출력 폴더 오류가 나와요.

등록이나 문서 저장이 완료됐다고 생각하지 말고 오류 안내를 확인하세요. 바탕화면 권한·기관 보안 제한 문제는 전산 담당자에게 확인받으세요. 일정 데이터나 백업 파일을 임의로 지우지 마세요.

프로그램이 이미 실행 중이라고 나와요.

작업 표시줄에서 열린 군수실 일정 관리 창을 확인하세요.

전산 담당자에게 전달하면 좋은 내용

문제가 발생한 버튼, 표시된 오류 문구, 발생 시각, 프로그램 버전, 사용 중인 한글 버전을 알려 주세요. 오류 기록 위치는 아래와 같습니다.

{{DATA_PATH}}\application.log

일정이나 메모가 포함된 화면·백업·오류 기록을 전달할 때는 기관에서 허용한 전달 경로를 사용하세요.

9. 배부·제출 전 확인

  • 날짜·요일·시간·참석 구분이 맞는가?
  • 장소와 주관부서가 최신 내용인가?
  • 미확정 일정은 담당자에게 확인했는가?
  • 주석·내부 연락·업무 메모를 배부 문서에 포함해도 되는가?
  • 기관이 요구한 형식(.hwp / .hwpx)이 맞는가?
  • 한글 또는 인쇄 미리보기에서 글자·용지 방향·페이지 수가 적절한가?
