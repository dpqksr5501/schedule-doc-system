보은군 · 군수실 일정 관리 2.1

처음 사용하실 때, 이 순서대로 해보세요.

일정은 한 번 입력하고, 일간·주간·월간 문서는 버튼으로 만듭니다.

1압축을 풀고 프로그램을 실행합니다.

ZIP 파일로 받았다면 마우스 오른쪽 버튼 → 압축 풀기를 선택하세요.
압축을 푼 폴더의 GunsuSchedule.exe를 두 번 누릅니다.

다음부터는 바탕화면의 군수실 일정 관리 바로가기를 사용하세요.

2일정을 입력하고 저장 완료를 확인합니다.

① ＋ 새 일정일자·시작 시간·행사명을 입력합니다.
② 장소·부서·참석 구분 확인군수님 / 부군수님 / 일반 행사를 고릅니다.
③ 저장하기저장한 뒤 화면 위쪽의 ‘저장 완료’를 확인합니다.
④ 양식·날짜 선택일일 일정표 / 주간 행사계획 / 월간 일정표

3한글 문서를 저장합니다.

한글 저장 (.hwp)을 누릅니다. 한글의 파일 접근 승인창이 나오면
이번에 만든 문서 경로를 확인하고 허용해 주세요. 최대 90초까지 기다립니다.

문서는 바탕화면 → 군수실_일정_출력문서
일일일정 / 주간일정 / 월간일정 폴더에서 찾으세요.
프로그램의 저장 폴더 열기로도 바로 찾을 수 있습니다.

4주석과 업무 메모를 구분합니다.

출력 주석: ‘주민 대표 3명 참석 · 인사말 3분’처럼 짧은 안내를 적습니다.
출력 주석 포함을 선택하면 행사 아래에 표시됩니다.

상세 업무 메모: 참석자·준비사항·연락사항·체크리스트를 기록합니다.
상세 업무자료 첨부를 선택하면 일정표 뒤에 별도 참고자료가 붙습니다.

두 옵션은 기본적으로 꺼져 있습니다. 제출·배부 전에 포함 내용을 확인하세요.

5실수는 복구하고, 일정은 백업합니다.

입력 실수 → 되돌리기　 /　 잘못 삭제 → 휴지통 → 복원
백업 · 복원 · 업데이트 → 지금 백업하기를 주기적으로 이용하세요.

저장한 일정이 안 보이면: 선택한 날짜와 ‘군수님 참석만’ 체크를 확인하세요.
HWP 저장에 실패하면: HWPX 중간 문서는 남습니다. 한글에서 열어
‘다른 이름으로 저장 → 한글 문서 (*.hwp)’를 선택하세요.
프로그램 실행·한글 연결이 안 되면 전산 담당자에게 확인을 요청하세요.
상세 설명: 프로그램 왼쪽 사용 방법 · 저장 위치
이 안내는 압축을 푼 폴더와 바탕화면 출력 폴더에 함께 보관됩니다.
