군수실 일정 관리 2.1 — 처음 사용하실 때

처음에는 [처음사용_5분안내.html]을 먼저 열어 주세요.
짧은 순서 안내이며, 인쇄해서 책상 옆에 두고 보셔도 됩니다.
이 설명서는 자세한 사용 방법과 문제 해결 안내입니다.

1. 내려받은 파일을 처음 실행할 때

GitHub 배포 화면에서 GunsuSchedule.exe를 내려받아 실행해 주세요.
ZIP 파일로 받으셨다면 먼저 마우스 오른쪽 버튼 → [압축 풀기]를 선택하고,
압축을 푼 폴더 안의 GunsuSchedule.exe를 두 번 눌러 주세요.
파이썬이나 개발 도구를 설치하실 필요는 없습니다.
기관 보안 정책으로 실행이 제한되면 전산 담당자에게 실행 파일을 확인받아 주세요.
Microsoft Edge WebView2가 없는 PC에서는 전산 담당자에게 설치를 요청해 주세요.

첫 실행이 정상적으로 완료되면 바탕화면에 다음 두 가지가 준비됩니다.

  [군수실 일정 관리] — 다음부터 프로그램을 여는 실행 바로가기
  [군수실_일정_출력문서] — 한글 문서와 백업을 찾는 출력 폴더

다음부터는 바탕화면의 [군수실 일정 관리]를 두 번 눌러 주세요.
다운로드 폴더의 실행 파일을 계속 찾으실 필요가 없습니다.
바로가기가 준비되었다는 것을 확인한 뒤 내려받은 실행 파일은 별도로 보관하셔도 됩니다.

2. 일정 입력과 문서 저장

처음 실행하면 화면 위쪽의 [사용 순서 안내]가 펼쳐집니다.
제목을 누르면 접을 수 있고, 필요할 때 다시 펼칠 수 있습니다.
일정이 없거나 선택한 기간에 표시할 일정이 없으면 입력·검색 안내가 나옵니다.

① [＋ 새 일정]을 누릅니다.
② 일자, 시작 시간, 행사명을 입력합니다. 장소와 주관부서도 확인합니다.
③ [저장하기]를 누르고 화면 위쪽의 [저장 완료]를 확인합니다.
④ 일일·주간·월간 양식을 고릅니다.
⑤ [한글 저장 (.hwp)]을 누릅니다. 저장한 파일이 있는 폴더가 열립니다.

[저장하기]는 일정 내용을 보관하고, [한글 저장 (.hwp)]은 배부할 문서를 만듭니다.
일정을 수정한 뒤에는 한글 문서를 다시 저장해야 수정 내용이 반영됩니다.

기본 [한글 저장 (.hwp)]은 실제 한글 문서 HWP 형식으로 저장합니다.
이 기능에는 HWPX를 열 수 있는 Windows용 한글 프로그램이 필요합니다.
한글의 파일 접근 승인창이 나타나면 이번에 생성한 문서 경로를 확인한 후 허용해 주세요.
저장은 최대 90초까지 기다립니다. 보안 승인창을 자동으로 누르지는 않습니다.

[HWP 저장에 실패했습니다]가 나오면 HWP 파일 저장이 완료된 상태가 아닙니다.
작업 내용은 HWPX 중간 문서로 남습니다. [HWPX 중간 문서 보기]로 찾아
한글에서 열고 [다른 이름으로 저장] → [한글 문서 (*.hwp)]를 선택해 주세요.
한글이 없거나 HWPX를 열지 못하는 PC라면 전산 담당자에게 확인을 요청해 주세요.

[HWPX 저장]은 HWPX가 필요한 경우에 따로 선택하는 버튼입니다.
기관에 제출할 문서가 HWP인지 파일 이름의 끝(.hwp)을 확인해 주세요.

[인쇄 / PDF]를 누르면 인쇄 화면이 열립니다.
프린터를 고르면 종이로 인쇄하고, PDF 저장을 고르면 PDF로 보관합니다.
긴 내용은 여러 페이지로 나누어 출력합니다. 인쇄 화면에서 페이지 수를 확인해 주세요.

3. 저장한 파일은 어디에 있나요?

바탕화면의 [군수실_일정_출력문서] 폴더를 열어 주세요.

  일일일정   → 하루 일정표
  주간일정   → 한 주의 행사계획
  월간일정   → 한 달의 달력형 일정표
  데이터백업 → 직접 만든 전체 일정 백업

파일 이름에 일정 날짜와 저장 시각이 붙습니다.
이미 열어 둔 한글 파일을 덮어쓰지 않고 새 파일로 보관합니다.
프로그램 아래쪽의 [저장 폴더 열기]로도 같은 폴더를 바로 열 수 있습니다.
[저장한 파일 보기]는 가장 최근에 만든 파일을 찾아줍니다.

Windows에서 바탕화면이 OneDrive나 기관 지정 위치로 옮겨져 있어도
Windows가 알려주는 실제 바탕화면 위치를 사용합니다.
정확한 경로는 [사용 방법 · 저장 위치] 화면에서 확인하실 수 있습니다.

4. 참석 예정자와 업무 메모

화면의 행사명을 누르면 일정 수정창이 열립니다.

  참석 예정자 / 주요 내빈 → 누가 참석하는지
  담당자 / 연락사항       → 누구에게 확인하거나 연락할지
  진행 · 준비사항         → 인사말, 자료, 이동, 사전 점검 등
  추가 업무 메모          → 변경 사항과 전달할 내용
  준비 확인 목록          → 필요한 일을 항목별로 기록하고 완료 표시

참석 구분과 중요도는 따로 고릅니다.
예를 들어 [군수님 참석]과 [중요]를 함께 선택할 수 있습니다.
[미확정]은 아직 확인이 필요한 일정입니다.
[취소]로 바꾼 일정은 전체 목록에 남지만 일반 일정표에는 출력되지 않습니다.

업무 메모는 기본 한글 문서와 인쇄물에 포함되지 않습니다.
내부 공유용 자료가 필요할 때만 [상세 업무자료 첨부]를 선택해 주세요.
전체 데이터 백업에는 업무 메모도 함께 보관됩니다.

5. 실수했을 때

최근 저장한 내용을 되돌리려면 [되돌리기]를 누릅니다.
입력칸 바깥에서는 Ctrl+Z로도 최근 변경을 되돌릴 수 있습니다.
되돌리기는 현재 실행 중인 동안 최근 30번의 변경을 기억합니다.

삭제한 일정은 [휴지통]에서 [복원]할 수 있습니다.
업무 메모와 준비 확인 목록도 함께 복원됩니다.

큰 실수나 데이터 문제가 생기면 [백업 · 복원 · 업데이트]에서
[자동 백업에서 복원] 또는 [백업 파일 선택]을 이용해 주세요.
복원하기 전에 일정 건수와 기간을 확인하는 창이 나옵니다.
현재 일정을 백업 내용으로 바꾸므로 날짜와 건수를 확인해 주세요.

6. 지난주 일정 가져오기와 빠른 입력

주간 화면의 [지난주 일정 가져오기]에서 필요한 행사만 선택합니다.
같은 날짜·시간·행사명의 동일 일정은 중복으로 만들지 않습니다.
새로 가져온 일정은 [미확정]으로 등록되므로 내용 확인 후 확정해 주세요.
참석자·메모 복사는 별도 선택이며, 확인 목록은 미완료로 바뀝니다.

[빠른 입력]에 ‘10/15 14:00 지역 현안 간담회’처럼 적으면
등록창에 날짜·시간·행사명이 미리 채워집니다.
내용을 확인한 뒤 저장해야 실제 일정이 등록됩니다.

7. 데이터 보관과 프로그램 업데이트

일정 데이터는 사용자 계정의 AppData\Roaming\GunsuSchedule에 보관합니다.
프로그램은 AppData\Local\GunsuSchedule의 버전별 폴더에 보관합니다.
출력 문서는 바탕화면의 출력 폴더에 보관합니다.

이 세 곳은 서로 다릅니다. 프로그램 업데이트가 일정 데이터를 덮어쓰지 않습니다.
AppData는 Windows의 숨김 폴더이므로 직접 찾아서 수정할 필요가 없습니다.

[지금 백업하기]를 주기적으로 눌러 주세요.
백업 파일은 기관에서 정한 안전한 저장 위치에도 따로 보관하는 것이 좋습니다.
같은 PC의 자동 백업만으로는 PC 고장에 대비할 수 없습니다.

업데이트는 [새 버전 확인] 후 직접 선택할 때만 진행합니다.
새 버전을 별도 폴더에 보관하고 정상 시작을 확인한 뒤 바로가기를 바꿉니다.
기존 버전은 바로 덮어쓰지 않습니다.
인터넷이 연결되지 않아도 이미 설치된 프로그램의 일정 관리는 가능합니다.

8. 문제가 생기면

[저장 실패]가 표시되면 등록 완료로 생각하지 마시고 안내 내용을 확인해 주세요.
출력 폴더를 만들 수 없으면 바탕화면의 접근 권한을 전산 담당자에게 확인받아 주세요.
프로그램이 이미 실행 중이라는 안내가 나오면 작업 표시줄의 열린 창을 확인합니다.

저장한 일정이 화면에 안 보이면 선택한 날짜를 먼저 확인해 주세요.
일일 화면에서 [군수님 참석만]을 선택하면 부군수님·일반 행사는 빠집니다.
체크를 해제하거나 [전체 일정 · 검색]에서 행사명을 찾아 주세요.
[취소] 일정도 일반 일정표에는 표시되지 않습니다.

실제로 업무 문서를 배부하거나 제출하기 전에는 아래 내용을 확인해 주세요.
  □ 날짜, 요일, 시간과 참석 구분이 맞는가?
  □ 장소와 주관부서가 최신 내용인가?
  □ 미확정 일정은 담당자에게 확인했는가?
  □ 내부 메모·연락사항을 배부 문서에 넣어도 되는가?
  □ 기관에서 요구한 파일 형식(.hwp / .hwpx)이 맞는가?
  □ 인쇄 미리보기에서 글자와 페이지 수가 적절한가?

용지는 A4를 사용합니다. 일일·주간은 세로, 월간은 가로입니다.
인쇄창의 용지 방향과 여백을 미리보기로 확인해 주세요.
브라우저 인쇄의 머리글·바닥글에 주소가 붙으면 해당 옵션을 꺼 주세요.

전산 담당자에게 전달할 오류 기록은
AppData\Roaming\GunsuSchedule\application.log에 있습니다.
일정 데이터와 백업 파일을 임의로 지우지 마세요.

9. 기관에서 사용하는 출력 양식과 주석

[일일 일정표]는 큰 제목, 시간, 행사명, 오른쪽 장소와 바깥 테두리로 출력합니다.
토요일이나 일요일을 고르면 [토·일 한 장에 묶기]로 두 날짜를 함께 출력합니다.
일정이 많으면 글자를 과도하게 줄이지 않고 다음 장으로 이어집니다.

[주간 행사계획]은 날짜별로 묶인 일자·시간·행사명·장소·부서 표입니다.
군수님 참석은 초록색, 부군수님 참석은 파란색, 일반 행사는 검정색입니다.
중요 일정은 참석 색상을 유지하고 [중요] 표시를 함께 넣습니다.

[월간 일정표]는 가로 A4, 월요일부터 일요일까지의 달력입니다.
주말 칸은 조금 좁으며, 날짜는 실제 달력으로 계산합니다.
월초와 월말 일정이 빠지지 않도록 해당 달 전체를 포함합니다.

[출력 주석]에는 행사 아래에 넣을 짧은 안내를 적습니다.
예: 주민 대표 3명 참석 / 군수님 인사말 3분 / 13:40 사전 점검
화면에서 [출력 주석 포함]을 선택한 경우에만 일정표에 표시합니다.

참석 예정자·연락사항·준비사항·업무 메모·확인 목록은 상세 업무자료입니다.
[상세 업무자료 첨부]를 선택하면 일정표 뒤에 별도 참고자료가 붙습니다.
긴 메모를 표 안에 모두 넣어 일정표가 밀리지 않도록 구성했습니다.
기본 공문서는 두 옵션이 모두 해제된 상태로 저장해 주세요.

미리보기에서 [용지 전체 보기]를 선택하면 창 너비에 맞춰 보입니다.
더 큰 글씨로 확인하려면 해제하고 문서를 좌우로 움직여 주세요. 인쇄와 한글 저장은 A4 크기로 출력합니다.
