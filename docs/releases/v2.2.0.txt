군수실 일정 관리 v2.2.0

고정 실행기와 실제 프로그램을 분리했습니다.

바탕화면 바로가기는 이제 버전별 EXE가 아닌 고정 실행기를 엽니다.
실행기는 검증된 설치 기록에서 열 버전을 선택합니다. 새 버전의 화면·일정 읽기와 연결 확인이 성공한 뒤 활성 버전을 전환하고, 이전 버전은 복구용으로 유지합니다.
인터넷 확인·다운로드는 프로그램의 백그라운드 업데이트 서비스가 담당하며, 다운로드 후 실행·시작 확인·실패 복구는 고정 실행기가 담당합니다.
업데이트 때마다 실행기나 바탕화면 바로가기를 교체하지 않습니다.

기존 2.1.3에서 바로 이전할 수 있습니다.

- [백업 · 복원 · 업데이트] → [새 버전 확인] → [다운로드 후 재시작]을 선택하세요. ZIP을 별도로 받을 필요는 없습니다.
- 바탕화면 실행 파일과 바로가기는 이름이 아닌 파일 내용과 연결 대상으로 식별합니다. 한글 이름이나 사용자가 바꾼 이름도 처리합니다.
- 기존 바로가기 이름을 가능한 한 유지해 고정 실행기로 연결하고, 확인된 중복 EXE·바로가기는 복구용 폴더로 보관합니다.
- 바로가기 이름을 나중에 바꿔도 새 아이콘을 매번 만들지 않습니다.
- 다른 프로그램·문서·확인되지 않은 파일은 옮기지 않습니다. 사용 중이거나 보관할 수 없는 항목은 남겨두고 다음 실행에서 다시 확인합니다.

일정·업무 메모·휴지통·설정의 저장 형식과 출력 문서 위치는 변경하지 않습니다.
기존 일정·직전 백업·자동 백업·출력 문서는 그대로 유지됩니다.
실행할 프로그램 파일이 누락·변경되면 검증된 이전 버전을 선택하며, 설치 기록도 직전 사본을 보관합니다.

처음 설치하는 분은 GunsuSchedule-v2.2.0-Windows.zip을 풀고 ‘군수실 일정 관리 설치.exe’를 실행하세요.
기관에서 사용하는 한글의 실제 인쇄 결과는 기존과 같이 해당 PC에서 확인해 주세요.
