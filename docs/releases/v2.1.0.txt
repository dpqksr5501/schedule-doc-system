군수실 일정 관리 v2.1.0

## 처음 설치하시는 분

**GunsuSchedule-v2.1.0-Windows.zip**을 내려받아 압축을 풀어 주세요.
먼저 **처음사용_5분안내.html**을 읽고, **GunsuSchedule.exe**를 두 번 누르면 됩니다.
GitHub의 **Source code(zip / tar.gz)**는 개발용 소스이므로 일반 사용자용 실행 파일이 아닙니다.

바탕화면에는 [군수실 일정 관리] 바로가기와 [군수실_일정_출력문서] 폴더가 준비됩니다.
이후에는 바로가기로 실행하고, 출력 문서는 일일일정 / 주간일정 / 월간일정에서 찾으세요.

## 이번 버전의 주요 개선

- 한 번 입력한 일정으로 기관 양식의 일간·주간·월간 문서를 생성합니다.
- 토·일 통합 일간, 주간 날짜 병합, 월간 가로 A4 달력을 지원합니다.
- 출력 주석과 내부 업무 메모를 구분하며, 상세 자료는 별도 참고 페이지에 붙습니다.
- 참석자·진행 준비·연락사항·준비 체크리스트를 함께 기록할 수 있습니다.
- 처음 사용 안내와 빈 화면의 입력·검색 안내를 추가했습니다.
- 일정 저장, 이전 상태 백업, 휴지통 복원과 데이터 복구를 강화했습니다.
- 새 버전의 실행 파일을 검증하고, 정상 시작 후 바로가기를 전환합니다.

## 기존 사용자의 업데이트

**기존 v1.0.1 사용자는 먼저 기존 프로그램에서 전체 일정 백업을 저장해 주세요.**
첫 전환에는 새 ZIP을 직접 내려받아 실행하는 방법을 권장합니다.
기존 자료가 보이지 않으면 백업 파일 선택에서 건수와 기간을 확인한 뒤 가져오세요.
v2.1.0 이후에는 [백업 · 복원 · 업데이트] → [새 버전 확인]으로 업데이트할 수 있습니다.

## 한글 문서 저장과 실행 환경

Windows 10/11 64비트와 Microsoft Edge WebView2가 필요합니다.
HWP 저장에는 HWPX를 열 수 있는 Windows용 한글이 필요합니다.
한글의 파일 접근 승인창이 나오면 이번 문서 경로를 확인하고 허용해 주세요.
HWP 저장 실패 시 HWPX 중간 문서를 보존합니다. 실패 안내를 저장 성공으로 판단하지 마세요.
기관에서 사용하는 한글 버전으로 글꼴·내용·인쇄 결과를 확인한 뒤 배부해 주세요.

## 검증 범위

Python 자동 검사 47개, JavaScript 검사, 배포 EXE의 데이터 저장·3종 HWPX 생성과
실제 WebView2 연결 검사를 통과했습니다.
개발 PC에서는 한글 자동화 연결이 안 되어 실제 HWP 변환과 기관 프린터 출력은 미검증입니다.
업데이트 전에는 지금 백업하기로 전체 일정을 보관해 주세요.
