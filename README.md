# 군수실 일정 통합 관리 시스템 (v1.0.0)

보은군 군수실 전용 원스톱 일정 관리 및 공문서(HWPX/HWP) 자동화 시스템

## 🌟 주요 기능
- **일일 일정표 / 주간 주요행사계획 / 월간 일정표** 단 1번 입력으로 동시 자동 생성
- **공문서 규격 한글(HWPX) 자동 생성**: 보은군 심볼/슬로건 로고 보존, 참석자별 컬러 자동 반영(군수님 초록, 부군수님 파랑, 일반 검정, 중요 빨강)
- **문서 작업 편의 기능**: 지난주 일정 원클릭 복사, 스마트 한 줄 빠른 입력, 실수 방지 휴지통
- **GitHub 자동 자가 패치(Auto-Updater)**: 새 버전 릴리즈 시 프로그램 내에서 원클릭으로 다운로드 및 자동 재실행 교체

## 🚀 빌드 방법
```bash
# 의존성 설치
pip install -r requirements.txt

# 단독 실행 파일(.exe) 빌드
build_exe.bat
```
빌드 완료 시 `dist/군수실_일정_관리_시스템.exe` 파일이 생성됩니다.
